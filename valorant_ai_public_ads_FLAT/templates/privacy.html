개인정보 처리방침

최종 업데이트: 2026년 9월 13일

1. 계정 및 인증 정보

회원가입 및 로그인에는 이메일 주소가 사용됩니다. 인증 정보는 Supabase Auth를 통해 처리되며, 서비스 서버는 로그인 세션 유지를 위해 보안 쿠키를 사용합니다. 비밀번호 원문을 서비스 코드나 자체 데이터베이스에 저장하지 않습니다.

2. 사용량 제한 정보

무료 분석 횟수 제한과 남용 방지를 위해 계정 식별자와 접속 IP를 사용할 수 있습니다. 일일 사용량 데이터베이스에는 계정 ID와 IP 주소 원문 대신 서버 비밀키로 생성한 해시 식별자를 저장하도록 구현되어 있습니다.

3. 업로드 영상

사용자가 업로드한 게임 영상은 분석을 위해 서버와 AI API 제공자에게 일시적으로 전송됩니다. 서버에 생성된 임시 영상 파일은 분석 요청이 끝난 뒤 삭제하도록 구현되어 있습니다. 외부 AI 제공자의 데이터 처리 조건은 해당 제공자의 정책이 적용될 수 있습니다.

4. 저장된 분석

로그인한 사용자의 성공한 분석은 다시 볼 수 있도록 계정별로 저장될 수 있습니다. 저장되는 항목에는 파일명, 분석 시각, 점수, 예상 티어, 에이전트·스킬 판별, 요약 및 장면별 피드백 등이 포함될 수 있습니다. 원본 영상 파일 자체는 분석 기록에 저장하지 않습니다.

5. 에이전트·스킬 학습 데이터

사용자가 에이전트 또는 스킬 판별을 직접 정정하고 ‘정답으로 학습’을 선택하면, 해당 영상 프레임에서 추출한 숫자 형태의 이미지 특징 벡터와 정답 라벨, 분석 식별자 등을 모델 개선 목적으로 저장할 수 있습니다. 학습 데이터베이스에는 원본 영상이나 캡처 이미지 자체를 저장하지 않으며, 저장된 특징 벡터를 이용해 별도 분류 모델의 학습 파라미터를 다시 계산합니다.

6. 일반 피드백

사용자가 제출한 분석 평가, 카테고리 및 자유 의견을 서비스 품질 개선 목적으로 저장할 수 있습니다. 영상 자체는 일반 피드백 레코드에 저장하지 않습니다.

7. 광고 및 쿠키

서비스가 Google AdSense 등 제3자 광고 서비스를 사용할 경우, 해당 사업자가 광고 제공·측정·부정 사용 방지 등을 위해 쿠키 또는 유사 기술을 사용할 수 있습니다. 로그인 세션 유지에도 필수 쿠키가 사용됩니다.

8. 보관 및 삭제

계정, 사용량, 저장된 분석, 학습 특징값 및 피드백 데이터는 서비스 운영, 남용 방지 및 품질 개선에 필요한 기간 동안 보관할 수 있습니다. 실제 공개 서비스 운영 정책에 따라 계정 삭제 및 관련 데이터 처리 절차를 추가할 수 있습니다.
