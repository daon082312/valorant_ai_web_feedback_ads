VALORANT AI Coach 사용 가이드

1. 로그인 후 영상을 선택하세요

홈 화면에서 VALORANT 플레이 영상을 선택합니다. 지원되는 영상 형식만 업로드할 수 있으며, 파일을 선택하면 파일명과 용량이 표시됩니다. 내 분석 페이지에서는 오른쪽 위의 새 영상 분석하기 버튼으로 홈 화면으로 돌아갈 수 있습니다.

2. 분석하기 좋은 클립

한두 번의 교전만 잘라낸 극단적으로 짧은 영상보다는 교전 전 준비, 진입, 교전, 교전 직후가 함께 보이는 클립이 좋습니다. 여러 라운드를 한꺼번에 올리는 것보다는 판단이 궁금한 구간이 포함된 비교적 짧은 클립이 효율적입니다.

3. HUD와 미니맵을 가급적 그대로 보여주세요

체력, 무기, 탄약, 스킬 상태, 미니맵 등 화면 정보가 보이면 포지셔닝과 유틸리티 사용을 해석하는 데 도움이 됩니다. 에이전트 학습 모델도 하단 HUD와 스킬 아이콘을 주요 시각 정보로 사용합니다.

4. 내 분석과 Premium은 창으로 열립니다

상단의 내 분석과 Premium은 현재 페이지를 떠나지 않고 화면 위의 창으로 열립니다. 팝업 안에서는 상단 네비게이션과 푸터를 숨기고 필요한 내용만 보여줍니다. 창 오른쪽 위의 × 버튼이나 바깥 영역을 누르면 원래 화면으로 돌아옵니다.

5. 분석 중에도 다른 메뉴를 확인할 수 있습니다

분석이 진행 중일 때 사용 가이드, About 등 사이트 안의 다른 메뉴를 눌러도 현재 분석 화면 위에 창으로 열립니다. 뒤에서는 영상 업로드와 AI 분석, 완료 후 자동 저장이 계속 진행됩니다. 분석 중 원래 페이지 자체를 새로고침하거나 닫으려 하면 브라우저가 확인 메시지를 표시합니다.

6. 에이전트와 스킬 판별은 실제 정정 데이터로 학습됩니다

분석 결과의 에이전트 판별 또는 장면별 스킬 판별이 틀렸다면 실제 이름을 입력하고 정답으로 학습을 누르세요. 사이트의 별도 이미지 분류 모델이 해당 영상 프레임에서 숫자 특징값을 추출하고, 저장된 정답 샘플로 클래스별 모델 가중치를 다시 계산합니다. 이후 충분한 샘플이 쌓이면 새 영상의 판별 결과를 자동으로 교차 확인하고 신뢰도가 높은 경우 Gemini 결과를 보정합니다.

학습을 위해 영상 원본이나 캡처 이미지를 별도 학습 데이터로 저장하지 않고, 모델 학습에 필요한 숫자 특징 벡터와 정답 라벨만 저장합니다. 한 종류의 정답만 배운 상태에서 무조건 그 답을 내지 않도록 서로 다른 라벨과 일정 수 이상의 샘플이 모인 뒤 자동 보정을 시작합니다.

7. 분석 결과는 여러 항목을 함께 보세요

결과에는 종합 점수, 예상 티어, 에이전트 판별, 조준, 움직임, 포지셔닝, 스킬 활용, 판단력 점수와 함께 장면별 코칭이 표시됩니다. 티어 예측은 실제 랭크나 MMR 조회 결과가 아니라 업로드한 클립에서 관찰된 플레이 수준을 추정한 값입니다.

8. 타임스탬프를 누르면 해당 장면으로 이동합니다

주요 장면의 시간 표시를 누르면 영상이 그 시점으로 이동합니다. 자동 재생은 되지 않으므로 장면을 멈춘 상태에서 직접 확인한 뒤 필요하면 재생 버튼을 눌러 앞뒤 상황을 비교할 수 있습니다.

9. 점수보다 장면별 관찰과 피드백을 우선하세요

종합 점수는 전체 플레이를 빠르게 요약하는 지표입니다. 실제 개선에는 특정 시점의 크로스헤어 위치, 노출 각도, 커버 활용, 이동, 유틸리티 사용, 교전 선택에 대한 설명이 더 중요합니다.

10. 성공한 분석은 자동으로 저장됩니다

로그인한 상태에서 분석이 성공하면 분석 결과가 자동으로 계정의 내 분석에 저장됩니다. 영상 원본 자체는 저장하지 않고 파일명, 분석 시각, 점수, 예상 티어, 요약, 장면별 피드백 등 분석 결과만 저장합니다.

11. 내 분석에서 다시 보기 또는 삭제할 수 있습니다

내 분석 창에서 저장된 분석 목록을 확인할 수 있습니다. 상세 보기를 통해 이전 결과를 다시 확인할 수 있고, 필요 없는 기록은 삭제할 수 있습니다. 삭제한 분석 기록은 목록에서 제거됩니다.

12. 틀린 피드백에는 평가를 남겨주세요

장면별 👍/👎와 전체 분석 평가를 남기면 이후 분석에서 어떤 영역을 더 보수적으로 판단해야 하는지 보정하는 데 사용됩니다. 에이전트/스킬의 정답으로 학습 기능과 일반 코칭 👍/👎 피드백은 서로 다른 학습 경로입니다.

13. 무료 분석 횟수와 Premium

무료 계정에는 일일 분석 횟수 제한과 동일 네트워크 기준 제한이 적용될 수 있습니다. 분석이 서버 오류로 실패한 경우에는 성공한 분석으로 처리되지 않도록 구성되어 있습니다. Premium 사용자는 사이트의 일일 분석 횟수 제한 없이 이용할 수 있지만, 외부 AI API 장애나 서비스 자체의 사용 한도까지 보장하는 것은 아닙니다.

14. 분석 결과는 참고용 코칭입니다

AI는 제한된 영상 프레임과 화면 정보를 바탕으로 판단합니다. 실제 플레이 의도, 음성 팀 정보, 보이지 않는 적의 위치, 네트워크 지연 등 영상 밖의 정보는 정확히 알 수 없으므로 결과를 절대적인 평가로 해석하지 않는 것이 좋습니다.
