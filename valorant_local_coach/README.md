# VALORANT Video Coach v7.2

실시간 게임 분석 없이 **녹화 영상 복기**를 중심으로 동작하는 로컬 코칭 프로그램입니다.

## v7.2 핵심

- 프로그램 내부 영상 재생/일시정지
- 타임라인 슬라이더로 원하는 초로 이동
- `-5초 / +5초` 이동
- 분석 후 이벤트 점프 목록
  - 내 킬 시점
  - 내 데스 시점
  - 스킬 사용 후보 시점
  - 사격 구간 시작 시점
  - 에임 평가 대표 시점
- 에임 평가 개선
  - 우선: 탄약 HUD 감소로 확인된 실제 발사 시점
  - 보조: 스킬/환경 킬을 위한 킬 시점 anchor
  - fallback: 여러 프레임에서 지속되는 적 윤곽 후보 장면
  - red / purple / yellow 적 윤곽색 자동 비교
  - 판정 방식과 신뢰도를 리포트에 표시
- K/D, 헤드라인, 무빙 안정성, 스킬 타이밍, 예상 티어, AI 코치 유지
- 원본 영상은 복사하거나 자동 저장하지 않음
- 게임 중 화면 캡처/키보드/마우스 훅 없음

## 실행

Windows에서 `run_windows.bat`을 실행하세요.

1. `영상 선택`
2. 필요하면 바로 재생/탐색
3. `분석 시작`
4. 분석 완료 후 오른쪽 이벤트 목록의 버튼을 눌러 해당 장면으로 이동
5. AI 코치에게 분석 결과 질문

## 에임 점수 주의

에임은 실제 게임 내부 좌표를 읽는 것이 아니라 영상의 적 윤곽과 화면 중앙 크로스헤어의 관계를 평가합니다. 탄약 HUD가 잘 잡히면 발사 시점 중심으로 평가하고, 사격 판독이 부족하면 지속적으로 보이는 적 후보 장면으로 보완합니다. fallback을 쓴 경우 신뢰도는 제한됩니다.

## 영상 플레이어

내장 플레이어는 OpenCV 기반으로 **영상 화면만 재생**합니다. 별도 오디오 재생 엔진은 포함하지 않습니다.

## 저장

분석 JSON 및 개인 학습 기준선만 `data/`에 저장합니다. 원본 영상은 프로그램 폴더로 복사하지 않습니다.
