# VALORANT Local Coach v6

API/Render 없이 Windows PC에서 실행되는 로컬 VALORANT 복기/코칭 프로그램입니다.

## v6 핵심 변경

- 둥근 카드/버튼 기반 CustomTkinter UI
- 흩어진 설정을 상단 `설정` 버튼 하나로 통합
  - 일반/성능
  - 스킬
  - 비전
  - 로컬 AI
- UI 멈춤/세션 시작 렉 완화
  - 프레임을 UI 큐에 계속 쌓지 않고 최신 프레임만 유지
  - 이벤트 큐 크기 제한 및 한 번에 처리할 이벤트 수 제한
  - 녹화 JPEG 인코딩을 백그라운드 처리
  - 녹화 버퍼 기본 6 FPS / 720px
  - Vision 기본 3 FPS, 최신 프레임만 처리
  - 학습 프레임 저장 기본 OFF
- **실제 발사 감지**
  - 좌클릭 횟수를 사격으로 세지 않음
  - 좌클릭은 발사 의도 후보로만 사용
  - 우측 하단 탄약 HUD가 실제로 변한 순간을 1발로 확정
  - 자동사격 중에도 탄약 HUD 변화마다 발사 이벤트 기록
- **실제 스킬 사용 감지**
  - Q/E/C/X 등 키 입력 자체는 사용으로 세지 않음
  - 사용자가 지정한 키는 어떤 스킬 슬롯인지 알려주는 후보 힌트
  - 해당 HUD 스킬 슬롯 상태가 연속 프레임에서 실제로 변해야 사용으로 확정
- WASD/Shift/Ctrl 무빙 분석
- 정지→첫 탄 시간, 반대방향 탭, 이동사격, 앉은 스프레이 분석
- 교전 전후 자동 녹화
- 미니맵 복기 및 적/아군 색상 후보 판독
- 헤드라인 추정 평가
- 측정값 기반 패배 요인 분석
- Ollama 로컬 AI 채팅
- 한국어/English 설정
- 교전 영상은 기본 24시간 후 자동 삭제(JSON 분석 기록은 유지)

## 설치/실행

Windows 10/11, Python 3.11~3.13에서 `run_windows.bat`을 실행하세요.

```bat
run_windows.bat
```

처음 실행할 때 필요한 Python 패키지를 자동 설치합니다.

## 로컬 AI

Ollama 사용 시 기본 모델은 `qwen3:4b`입니다.

```bat
ollama pull qwen3:4b
```

Ollama가 없어도 기본 규칙 기반 코칭은 동작합니다.

## HUD 판정 주의

탄약/스킬 HUD 위치는 해상도, 화면 비율, HUD 배율에 따라 조금 달라질 수 있습니다. 기본값은 일반적인 16:9 VALORANT HUD를 기준으로 합니다. 실제 발사나 스킬 사용이 잘 잡히지 않으면 `설정`에서 HUD 감지 민감도를 조정할 수 있습니다.

아군/적 및 헤드라인 판독은 현재 색상/형태 기반 로컬 컴퓨터비전 휴리스틱입니다. 낮은 신뢰도의 장면은 확정 판정하지 않습니다.

## 저장 위치

- 교전 영상: `data/fight_clips/`
- 세션 분석: `data/sessions/`
- 기준 세션: `data/reference_sessions/`

모든 데이터는 기본적으로 사용자 PC에만 저장됩니다.
