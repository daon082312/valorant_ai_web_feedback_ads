# VALORANT Video Coach v7.10

녹화된 VALORANT 영상을 오프라인으로 분석하는 영상 복기 코치입니다.

## v7.10 변경

- 기존 중앙 킬 마커/데스 리포트 기반 K/D 자동 감지를 제거했습니다.
- **오른쪽 위 킬로그(killfeed)만 사용해 내 킬을 판정**합니다.
  - 새 킬로그 행이 나타난 순간을 감지합니다.
  - VALORANT에서 자신의 킬에 표시되는 추가 강조 테두리를 판독합니다.
  - 팀원 킬은 카운트하지 않습니다.
  - 스킬 킬도 킬로그에 자신의 킬로 표시되면 카운트 대상입니다.
  - 새 항목 때문에 기존 행이 아래로 밀리는 현상은 중복 킬로 세지 않습니다.
- 데스는 분석하지 않습니다. 상단 `내 K/D` 카드는 `킬로그 킬`로 변경됩니다.
- K/D 수동 교정/+데스 UI를 제거했습니다.
- 이벤트 목록의 킬 항목은 `킬로그 · 내 킬`로 표시되고 클릭하면 해당 시점으로 이동합니다.
- AI 코치도 데스/KD 대신 킬로그 기반 내 킬 수만 사용합니다.
- v7.9의 고정 영상 뷰포트, 최신 프레임 1장 큐, 전체화면/재생 안정화는 유지합니다.

## 실행

Windows에서 `run_windows.bat` 실행 → 영상 선택 → 분석 시작.

## 제한

킬 판독은 OCR이나 Riot API가 아니라 화면 영상의 킬로그 강조 테두리를 이용합니다. 영상이 잘렸거나 HUD 배율이 크게 다르거나 리플레이/관전자 UI가 일반 1인칭 HUD와 다르면 누락/오탐이 생길 수 있습니다.
