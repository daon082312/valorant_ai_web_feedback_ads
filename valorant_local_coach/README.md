# VALORANT Video Coach v7.15

## v7.15 변경
- EVENT JUMP 오른쪽 패널을 기존 위젯 위에 덧붙이지 않고 완전히 새로 생성해 중복/겹침 제거
- 스킬 HUD 변화 감지를 강화
  - 강한 변화는 1회만으로 스킬 후보 인정
  - 중간 변화는 2회 연속일 때 인정
  - 최종 스킬 이벤트를 교전 타이밍과 비교해 스킬 점수 산출
- 일반 모드에서 스킬 근거가 전혀 없으면 `—` 대신 낮은 신뢰도의 중립 스킬 점수 표시
- 최종 스킬 점수를 v7.14 티어 계산에 다시 반영
- AI 채팅 입력창과 전송 버튼을 네이티브 Tk 위젯으로 새로 만들고 결과 큐 폴러를 예외 안전하게 수정
- Ollama가 없거나 연결되지 않아도 내장 코치 fallback 답변 유지
- v7.14의 티어 가중치(에임 31%, 헤드라인 10%, 무빙 27%, 스킬 20%, 스프레이 12%), 레디언트 포함 단일 티어 표시 유지

Windows에서 `run_windows.bat`을 실행하세요.
