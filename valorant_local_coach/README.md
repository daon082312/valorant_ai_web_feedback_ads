# VALORANT Video Coach v7.6

녹화 영상 복기 중심의 로컬 VALORANT 코치입니다.

## v7.6 변경
- 영상 디코딩을 Tk UI 스레드에서 분리해 재생 중 프로그램 멈춤 완화
- UI에는 최신 프레임만 전달해 긴 영상/고해상도 영상의 프레임 적체 방지
- 분석 시작 시 영상 재생 자동 일시정지
- **영상 전용 전체화면** 추가
  - `⛶ 전체화면` 버튼
  - 영상 더블클릭 또는 F11로 진입
  - ESC/F11/더블클릭으로 종료
  - 메인 프로그램 창을 최대화하지 않고 영상만 별도 검은 전체화면 창에 표시
  - 영상 종횡비 유지
- 메인 창이 커져도 메인 플레이어 렌더 크기를 제한해 불필요한 이미지 확대/레이아웃 부담 감소
- v7.5의 AI 채팅 큐 방식, K/D 수동 교정, v7.4 점수 보정 유지

## 실행
`run_windows.bat` 실행 → 영상 선택 → 재생.

영상 자체를 크게 보려면 메인 창을 최대화하지 말고 `⛶ 전체화면`을 사용하세요.
