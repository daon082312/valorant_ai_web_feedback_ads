# VALORANT Video Coach v7.5

실시간 캡처 없이 녹화된 VALORANT 영상을 로컬에서 분석/복기하는 버전입니다.

## v7.5 핵심 변경

- **AI 채팅 경로 재작성**
  - 입력창을 Windows 표준 `tk.Text`로 변경
  - Enter 전송, Shift+Enter 줄바꿈
  - AI 백그라운드 스레드는 Tkinter를 직접 건드리지 않고 응답 큐에만 기록
  - 메인 UI 스레드가 큐를 읽어 답변 표시
  - Ollama가 없거나 모델이 설치되지 않아도 내장 코치가 답변
- **K/D 자동 감지 v3**
  - 킬: 하단 중앙 본인 킬 확인 영역의 중첩 ROI가 동시에 짧게 변할 때만 판정
  - 데스: 살아있는 탄약 HUD 확인 → 탄약 HUD 소실 → 우측 전투 리포트 지속의 상태 전환으로 판정
  - 한 번 데스로 들어간 뒤 살아있는 HUD가 복귀하기 전에는 추가 데스를 세지 않음
- **K/D 수동 교정**
  - 잘못 감지된 킬/데스 이벤트 옆 `×` 버튼으로 삭제
  - 영상의 현재 재생 위치에서 `현재 +킬`, `현재 +데스` 추가
  - `자동 복원`으로 원래 자동 판독으로 되돌림
  - 교정된 K/D는 즉시 상단 카드와 AI 코치 컨텍스트에 반영
- v7.4의 에임/무빙/티어 재보정과 영상 플레이어/이벤트 점프 유지

## 사용

Windows에서 `run_windows.bat` 실행 → 영상 선택 → 분석 시작.

K/D 자동 판독이 영상의 해상도/HUD 배율 때문에 틀리면 이벤트 목록에서 직접 교정할 수 있습니다. 원본 영상은 복사하지 않습니다.
