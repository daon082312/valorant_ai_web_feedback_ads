# VALORANT Video Coach v7.1

실시간 캡처 없이 녹화된 VALORANT 영상을 로컬에서 분석하는 영상 우선 코칭 프로그램입니다.

## v7.1 핵심

- 게임 중 실시간 화면 캡처/키보드/마우스 훅 없음
- 영상 선택 → 분석 → 점수/티어 → 상세 피드백 → AI 코치
- 영상 분석 기본 8 FPS
- **에임 판독 개선**
  - 실제 탄약 감소로 확인된 발사 시점 ±0.38초만 평가
  - red / purple / yellow 적 윤곽색을 영상 전체에서 자동 비교
  - 여러 프레임에서 같은 위치에 지속되는 적 후보를 우선 사용
  - 신뢰할 수 없는 발사는 점수에서 제외
- **내 킬/내 데스 판독 개선**
  - 영상별 롤링 기준선을 자동 학습
  - 킬은 하단 중앙 킬 확인 마커의 짧은 변화 피크를 감지
  - 데스는 탄약 숫자 HUD 소실 + 우측 전투 리포트 전환을 함께 확인
  - 총기 발사는 킬 신뢰도 보조 신호일 뿐 필수 조건이 아님
- 헤드라인, 무빙 안정성, 스프레이, 스킬 타이밍, 예상 티어
- 개인 플레이 자동 학습
- 원본 영상은 복사/저장하지 않고 JSON 분석 결과만 `data/video_reviews/`에 저장

## 실행

Windows 10/11, Python 3.11~3.13에서 `run_windows.bat` 실행.

정확도를 위해 영상 분석 FPS는 8 이상을 권장합니다.

## 판독 한계

K/D와 에임은 게임 메모리/API가 아니라 화면 영상만 이용하는 로컬 CV 추정입니다. HUD 배율, 해상도, 영상 크롭, 스트리밍 오버레이, 색보정에 따라 오차가 생길 수 있습니다. 특정 영상에서 반복 오인식되면 그 영상 일부를 기준으로 ROI/임계값을 보정하는 것이 가장 정확합니다.
