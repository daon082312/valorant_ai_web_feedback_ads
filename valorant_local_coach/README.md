# VALORANT Video Coach v7.13

UI 겹침과 에임/티어 밸런스를 수정한 버전입니다.

## v7.13 변경
- EVENT JUMP 패널의 기존 제목/상태 위젯을 모두 정리하고 제목 1세트 + 상태 1줄 + 이벤트 목록 1개만 구성
- 오른쪽 이벤트 패널 폭과 이벤트 버튼 여백을 늘려 겹침 방지
- 에임 점수를 원시 측정값보다 소폭 상향 보정
  - 예: 65 → 69.5, 75 → 79.5, 85 → 88.2
- 분석 단계와 UI 표시 직전 양쪽에서 같은 보정 버전을 확인해 카드 숫자에 실제 반영
- 플래티넘 이상 티어는 더 높은 에임 기준을 요구
  - 플래티넘 62+
  - 다이아몬드 72+
  - 초월자 80+
  - 불멸 88+
  - 레디언트 95+
- 티어는 아이언~레디언트 중 정확히 1개만 표시하고 티어별 글자색 유지
- v7.10의 오른쪽 위 킬로그 기반 내 킬 감지와 v7.9의 영상 재생 안정화 유지

Windows에서 `run_windows.bat`을 실행하세요.
