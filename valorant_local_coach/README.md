# VALORANT Video Coach v7.9

영상 재생 UI 안정화 버전입니다.

## v7.9 변경
- 메인 영상 뷰포트를 고정해 영상 프레임 크기가 피드백 탭/레이아웃을 밀어내지 않도록 수정
- 피드백 탭을 열면 네이티브 영상 위젯을 명시적으로 숨겨 겹침/떨림 방지
- 메인 영상 UI 갱신을 최대 15 FPS로 제한
- 전체화면에서는 메인 영상까지 동시에 다시 그리지 않음
- PIL LANCZOS 대신 OpenCV 기반 빠른 리사이즈 사용
- 비동기 디코더는 영상 프레임을 최신 1장만 유지해 1080p/고해상도 영상의 메모리 폭증 방지
- meta/seek/eof/error 제어 메시지는 그대로 보존
- v7.8의 영상 전체화면, 재생/seek 상태 유지, K/D 교정, AI 채팅 유지

## 실행
새 폴더에 압축 해제한 뒤 `run_windows.bat`을 실행하세요.
