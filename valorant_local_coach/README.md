# VALORANT Video Coach v7.3

실시간 게임 분석 없이 녹화된 VALORANT 영상을 로컬에서 복기하는 영상 우선 코치입니다.

## v7.3 변경
- AI 질문 입력창을 Windows 표준 Tk Entry로 교체해 Python 3.13/한글 IME 포커스 문제 완화
- Ollama가 없거나 모델이 설치되지 않아도 내장 코치가 즉시 답변
- 에임 점수 재보정
  - 같은 자동연사 프레임을 여러 번 점수에 넣지 않음
  - 발사 시점 약 ±0.22초만 사용
  - 지속되는 적 후보 중 크로스헤어에 가장 가까운 대상을 우선 선택
  - 설정된 적 윤곽색을 우선 사용하고 근거가 부족할 때만 자동 색상 선택
  - 적 박스 크기 대신 화면 높이 대비 조준 오차로 점수 정규화
  - 에임 점수 옆에 판정 신뢰도 표시
- v7.2의 내장 영상 플레이어와 킬/데스/스킬/사격/에임 이벤트 점프 유지

## 실행
Windows에서 `run_windows.bat` 실행 → 영상 선택 → 분석 시작.

## 에임 점수 해석
에임 점수는 실제 발사 직전/직후의 크로스헤어와 지속 적 후보의 머리 추정점 사이 거리로 계산합니다. 발사 근거가 부족하면 지속 적 후보를 fallback으로 사용할 수 있으나 이 경우 신뢰도는 낮게 표시됩니다. 신뢰할 수 있는 근거가 없으면 억지 점수를 만들지 않습니다.

## AI 코치
오른쪽 입력칸은 Windows 표준 Tk 입력 위젯입니다. Enter 또는 `전송` 버튼으로 질문할 수 있습니다. Ollama `qwen3:4b`가 실행 중이면 로컬 모델을 사용하고, 그렇지 않으면 측정값 기반 내장 코치가 답합니다.

## 주의
K/D와 에임은 게임 메모리/API가 아닌 화면 영상 기반 추정입니다. HUD 크롭, 색보정, 적 윤곽 설정, 해상도에 따라 오차가 생길 수 있습니다. 이벤트 점프의 에임 장면을 직접 확인해 판정 근거를 검증할 수 있습니다.
