# VALORANT Video Coach v7.7

녹화된 VALORANT 영상을 오프라인으로 분석하고, 영상 재생/이벤트 이동/AI 코칭을 제공하는 버전입니다.

## v7.7 변경
- K/D 교정 버튼과 이벤트 초 이동 영역을 완전히 분리
  - `+ 킬`, `+ 데스`, `자동 K/D로 복원`은 K/D 교정 박스에만 표시
  - 킬/데스/스킬/사격/에임 이벤트는 아래 이벤트 목록에서 클릭해 해당 초로 이동
- 메인 영상 재생 컨트롤을 grid로 다시 배치해 버튼 겹침 방지
- 영상 전용 전체화면 플레이어 개선
  - `← 돌아가기`
  - `-5초 / +5초`
  - `재생 / 일시정지`
  - 전체화면 타임라인
  - 현재 시간 / 전체 시간
  - `Space`: 재생/일시정지
  - `← / →`: 5초 이동
  - `Esc` 또는 `F11`: 전체화면 종료
- 전체화면에서도 재생 상태가 메인 플레이어와 동기화
- 전체화면 영상은 하단 컨트롤 영역을 제외한 실제 영상 영역에 종횡비를 유지해 표시
- 디코더 큐에서 meta/seek/eof/error 메시지를 보존하도록 수정해 타임라인·5초 이동 안정성 개선
- v7.6의 비동기 영상 디코딩, v7.5의 AI 채팅/K/D 교정 유지

## 실행
Windows에서 `run_windows.bat` 실행 → 영상 선택 → 필요하면 분석 시작.

메인 프로그램 창을 최대화할 필요가 없습니다. 영상만 크게 보려면 `⛶ 영상 전체화면` 버튼을 사용하세요.
