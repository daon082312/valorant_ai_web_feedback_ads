# VALORANT Video Coach v7.8

녹화 영상 복기 중심의 로컬 VALORANT 코치입니다.

## v7.8 변경
- K/D 교정 버튼을 이벤트 초 이동 목록과 완전히 분리
  - 이벤트 목록에는 시간 이동만 표시
  - `K/D 교정` 버튼을 누르면 별도 작은 창에서 +킬 / +데스 / 자동 복원
- 영상 전체화면 안정화
  - 메인 창 최대화가 아니라 영상 전용 borderless 화면크기 창
  - Windows/Tk의 `-fullscreen` 의존 제거
  - 전체화면 하단에 ← 돌아가기 / -5초 / 재생·일시정지 / +5초 / 타임라인
  - ESC/F11로 뒤로가기, Space로 재생·일시정지, 방향키로 ±5초
- seek 상태 경합 수정
  - 디코더에서 `seek + 재생 상태 유지`를 하나의 명령으로 처리
  - ±5초, 타임라인, 이벤트 점프 후 재생이 멈추는 문제 완화
- 전체화면 종료 시 메인 창의 `영상 · 이벤트` 탭으로 명시적으로 복귀

## 실행
`run_windows.bat` 실행 → 영상 선택 → 재생.
