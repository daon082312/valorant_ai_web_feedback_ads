# VALORANT Local Coach v3

API/Render 없이 Windows PC에서 실행되는 로컬 코칭 프로그램입니다. 기존 웹사이트의 다크 카드 UI를 옮기고, 무빙 입력·스킬 키·교전 자동 녹화를 한 프로그램에 통합했습니다.

## v3에서 되는 것

- 모니터 화면 실시간 로컬 캡처
- WASD, Shift, Ctrl 입력 추적
- 왼쪽 클릭 사격 감지
- 사용자가 직접 스킬 키를 설정
  - 1번 스킬 / 2번 스킬 / 3번 스킬 / 궁극기
  - 예: `1번 스킬 = Q`
  - 숫자키, 문자키, `mouse4`, `mouse5` 지원
- 교전 자동 분리
- 이동사격, Shift 워크 사격, Ctrl 앉은 사격 분석
- 이동키 해제 → 첫 탄 시간(ms) 분석
- A↔D / W↔S 반대방향 탭 분석
- 긴 스프레이 / 앉은 스프레이 분석
- 교전 전후 화면 자동 녹화
  - 기본: 첫 탄 약 4초 전부터 마지막 탄 약 1.5초 후까지
  - `data/fight_clips/<세션>/`에 MP4(환경에 따라 AVI fallback) 저장
  - 같은 이름의 JSON에 무빙/스킬 타임라인 저장
- 스킬 사용 타이밍 피드백
  - 교전 전 셋업
  - 교전 중 사용
  - 교전 후 늦은 사용 가능성
- 프로/기준 무빙 프로필과 비교
- 세션 JSON 및 학습 후보 프레임 저장

## 중요한 한계

현재 스킬 평가는 **키 입력 시점과 교전 타임라인**을 기반으로 합니다. 예를 들어 스킬을 교전 전에 준비했는지, 교전이 끝난 뒤 늦게 눌렀는지는 판단할 수 있습니다.

하지만 연막이 실제로 시야를 잘 막았는지, 플래시가 적에게 맞았는지, 몰리가 좋은 위치에 들어갔는지 같은 **실제 스킬 효과**는 화면 Vision 모델이 추가되어야 정확히 평가할 수 있습니다. 교전 영상을 자동 저장하는 이유가 다음 단계의 Vision AI 학습/검증에 바로 쓰기 위해서입니다.

## 설치

Windows 10/11 + Python 3.11 또는 3.12 권장.

가장 간단한 방법은 `run_windows.bat` 더블클릭입니다.

수동 설치:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 스킬 키 설정

프로그램 상단의 `스킬 키 설정` 버튼을 누릅니다.

예:

- 1번 스킬: `q`
- 2번 스킬: `e`
- 3번 스킬: `c`
- 궁극기: `x`

키를 다르게 쓰는 경우 그대로 입력하면 됩니다. 설정은 `config.json`에 저장되고 다음 세션부터 자동 적용됩니다. 세션 중 바꿔도 이후 입력부터 새 설정을 사용합니다.

## 교전 녹화 위치

- `data/fight_clips/<세션>/fight_XXX_HHMMSS.mp4`
- `data/fight_clips/<세션>/fight_XXX_HHMMSS.json`

JSON에는 해당 교전의 무빙 점수, 정지→첫 탄 시간, 스킬 사용 시각/슬롯/키/교전 단계가 들어갑니다.

## 기준 무빙 학습

`data/reference_sessions/`에 이 프로그램으로 기록한 기준 세션 JSON을 최소 3개 넣고 `기준 세션 학습` 버튼을 누르면 `pro_baseline.json`이 새 기준으로 갱신됩니다.

초기 `Pro-style` 값은 실제 프로 선수 키로그를 측정한 데이터가 아니라 시작용 휴리스틱입니다. 실제 프로가 이 프로그램을 켜고 플레이한 세션이나 신뢰할 수 있는 입력 데이터가 확보되면 그 데이터로 기준을 교체하는 것이 정확합니다.

## EXE 만들기

`build_windows.bat`을 실행하면 PyInstaller로 Windows 실행 파일을 만들 수 있습니다.
