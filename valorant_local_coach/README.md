# VALORANT Video Coach v7.4

실시간 분석 없이 녹화 영상을 복기하는 로컬 VALORANT 코칭 프로그램입니다.

## v7.4 변경
- 에임 점수 재보정
  - 적 윤곽의 한 점을 정확한 머리로 가정하지 않고 `head zone`으로 평가
  - 실제 발사/킬 시점 근거가 하나라도 있으면 일반 장면 fallback이 점수를 끌어내리지 않음
  - 화면 해상도 대비 보정거리로 계산하며 일반적인 마이크로 보정은 과도하게 감점하지 않음
- 무빙/사격 안정성 재보정
  - 절대 화면 움직임이 아니라 해당 영상의 평소 카메라 움직임 대비 사격 순간의 과도한 움직임만 감점
  - 플릭/트래킹 자체를 이동사격으로 간주하지 않음
  - 긴 스프레이 감점 기준도 완화
- 예상 티어 재설계
  - 단일 영상에서 근거가 부족하면 정확한 한 티어 대신 `골드~플래티넘` 같은 범위로 표시
  - 신뢰도가 낮은 에임/스킬 측정치는 티어 계산 영향력이 자동으로 감소
  - 실제 Riot 계정 랭크가 아니라 영상 기반 기계적 플레이 범위 추정
- 영상 플레이어, 이벤트 점프, Windows 표준 AI 질문 입력창 유지

## 실행
Windows에서 `run_windows.bat`을 실행하세요.
