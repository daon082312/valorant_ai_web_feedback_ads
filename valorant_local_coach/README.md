# VALORANT Video Coach v7

실시간 게임 분석을 제거하고 **녹화 영상 분석을 메인**으로 만든 경량 버전입니다.

## 핵심 기능
- 게임 실행 중 화면 캡처/키보드/마우스 추적 없음
- MP4/MOV/AVI/MKV/WEBM 영상 선택 후 오프라인 분석
- 에임 점수, 헤드라인, 영상 기반 무빙/사격 안정성, 스킬 타이밍 후보 점수
- 탄약 HUD 감소 기반 발사 수/버스트 분석
- 본인 킬/데스 HUD의 보수적 추정
- 예상 티어(Iron~Immortal)와 신뢰도
- 분석 결과를 이용하는 로컬 AI 코치(Ollama, 미설치 시 내장 fallback)
- 분석한 영상을 기반으로 개인 기준선 자동 학습

## 티어 예측 주의
티어 예측은 실제 Riot 계정 랭크를 조회하지 않습니다. 영상에서 측정 가능한 에임/헤드라인/사격 안정성/스킬 타이밍 지표를 조합한 코칭용 추정치입니다. 단일 영상이 짧거나 적 판독이 적으면 신뢰도가 낮아집니다.

## 실행
`run_windows.bat` 실행 → `영상 선택` → `분석 시작`.

분석 FPS는 설정에서 2/3/4/6/8로 조절할 수 있습니다. 낮을수록 CPU 사용량이 줄어듭니다.

## 로컬 AI
Ollama 사용 시 기본 모델은 `qwen3:4b`입니다. Ollama가 없거나 모델이 설치되지 않았으면 영상 측정값 기반 내장 코치가 답변합니다.

## 저장 위치
분석 리포트와 개인 학습 기준선은 `data/` 아래에 저장되며, 원본 영상은 복사하거나 자동 저장하지 않습니다.
