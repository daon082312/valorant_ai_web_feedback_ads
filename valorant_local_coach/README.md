# VALORANT Video Coach v7.11

티어 표시를 먼저 수정한 버전입니다.

## v7.11 변경
- 예상 티어를 범위가 아니라 **정확히 1개**만 표시
- 9개 티어 전체 지원: 아이언 / 브론즈 / 실버 / 골드 / 플래티넘 / 다이아몬드 / 초월자 / 불멸 / 레디언트
- 레디언트 최고 구간 추가
- 상단 예상 티어 값의 글자색을 티어별 고유 색상으로 표시
- 기존 신뢰도 계산은 유지하되, 신뢰도가 낮아도 범위로 넓히지 않고 하나의 티어를 표시
- v7.10의 오른쪽 위 킬로그 기반 내 킬 분석, 영상 플레이어, AI 채팅 유지

## 티어 색상
- 아이언: 회색
- 브론즈: 브론즈
- 실버: 실버
- 골드: 골드
- 플래티넘: 청록
- 다이아몬드: 블루
- 초월자: 그린
- 불멸: 핑크/레드
- 레디언트: 밝은 골드/크림

## 주의
예상 티어는 Riot 계정 랭크 조회가 아니라 영상에서 측정한 기계적 플레이 지표 기반 추정입니다.

Windows에서 `run_windows.bat`을 실행하세요.
